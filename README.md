# RAG Document Intelligence System

A production-grade Retrieval-Augmented Generation (RAG) pipeline for multi-document question answering with hybrid retrieval, cross-encoder reranking, relevance guardrail, citation-grounded generation, and RAGAS evaluation.

---

## Architecture

```
PDF Upload
    │
    ▼
Ingestion (PyMuPDF + RecursiveCharacterTextSplitter)
    │  chunks tagged with doc_name, page_number, chunk_id
    ▼
ChromaDB (PersistentClient, cosine similarity)
    │
    ├─────────────────────────┐
    │                         │
    ▼                         ▼
Semantic Search           BM25 Search
(all-mpnet-base-v2)       (rank_bm25)
top 20                    top 20
    │                         │
    └──────────┬──────────────┘
               │
               ▼
    Reciprocal Rank Fusion (k=60)
               │
               ▼
    Cross-Encoder Reranking
    (ms-marco-MiniLM-L-6-v2)
    top 20 → top 5
               │
               ▼
    Relevance Guardrail
    (reject if score below threshold)
               │
               ▼
    Generation (Groq LLaMA 3.3 70B)
    Citation prompt → (Source: filename, Page X)
               │
               ▼
    Streamlit Chat Interface
```

---

## Tech Stack

| Component | Technology |
|---|---|
| PDF Extraction | PyMuPDF (fitz) |
| Text Splitting | LangChain RecursiveCharacterTextSplitter |
| Embeddings | sentence-transformers/all-mpnet-base-v2 (local) |
| Vector Store | ChromaDB PersistentClient |
| Keyword Search | rank-bm25 (BM25Okapi) |
| Rank Fusion | Reciprocal Rank Fusion (k=60) |
| Reranking | cross-encoder/ms-marco-MiniLM-L-6-v2 |
| Generation | Groq LLaMA 3.3 70B via langchain-groq |
| Memory | LangChain ConversationBufferMemory |
| Evaluation | RAGAS (Faithfulness, Answer Relevancy, Context Precision) |
| Frontend | Streamlit |

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/rag-doc-intelligence.git
cd rag-doc-intelligence
```

### 2. Create and activate virtual environment

```bash
python -m venv venv
```

```bash
# Mac/Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Set up environment variables

Create a `.env` file in the project root:

```
GROQ_API_KEY=your_groq_api_key_here
HF_TOKEN=your_huggingface_token_here
```

Get your free Groq API key at: https://console.groq.com

Get your free HuggingFace token at: https://huggingface.co/settings/tokens

### 5. Create required folders

```bash
mkdir data
mkdir chroma_store
```

## Running the App

```bash
streamlit run app.py
```

Open http://localhost:8501 in your browser.

**Workflow:**
1. Upload one or more PDF files using the sidebar
2. Click **Ingest Documents** and wait for processing
3. Type your question in the chat box
4. Get cited answers with expandable source references

## Key Design Decisions

**Hybrid Retrieval over pure vector search**
Pure semantic search fails on keyword-heavy queries such as model names, equations, and abbreviations. BM25 handles exact term matching. Merging both with Reciprocal Rank Fusion gives better recall than either alone.

**Two-stage retrieval with cross-encoder reranking**
Bi-encoders encode query and document independently — fast but lossy. The cross-encoder reads query and document together through full BERT inference, capturing interaction signals the bi-encoder misses. Using bi-encoder for recall (top 20) and cross-encoder for precision (top 5) balances speed and accuracy.

**Relevance guardrail**
Prevents the LLM from hallucinating answers to out-of-scope queries. Calibrated empirically on known-answerable queries from the actual document rather than using an arbitrary fixed threshold.

**Citation-grounded generation**
Context chunks are labeled with `[Chunk N] Source: filename, Page X` before injection into the prompt. The model copies these labels rather than generating citations from memory, eliminating hallucinated citations.

**Session-scoped memory**
ConversationBufferMemory preserves the last 6 conversation turns per session. Allows follow-up questions and pronoun resolution without unbounded context growth.
